# Автотесты API для сервиса Ez-scooter

## Описание
Проект содержит автотест, проверяющий сценарий создания заказа и получения данных о нем по трек-номеру.

## Шаги теста:
1. Создание заказа (POST /api/v1/orders).
2. Сохранение трека из ответа.
3. Запрос данных заказа по треку (GET /api/v1/orders/track).
4. Проверка кода ответа 200.

## Запуск
Установите зависимости: `pip install requests pytest`
Запустите тест: `pytest test_create_order.py`
